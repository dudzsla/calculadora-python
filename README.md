# calculadora-python
Calculadora em Python com script Bash, desenvolvido para uma atividade da EBAC.

A calculadora permite escolher entre quatro operações matemáticas: adição, subtração, multiplicação e divisão. Depois, o usuário informa dois números para realizar a operação escolhida, e o programa apresenta o resultado final.

A calculadora também possui alguns tratamentos de erros. Caso o usuário tente dividir por zero, o programa apresenta a mensagem "Erro: Divisão por zero não é permitida.". Se escolher uma opção diferente das quatro operações disponíveis, aparece a mensagem "Opção inválida. Tente novamente.". Por fim, caso digite um valor que não seja um número válido, o programa apresenta a mensagem "Entrada inválida. Por favor, insira números válidos.".
