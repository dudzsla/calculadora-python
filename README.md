# calculadora-python
Calculadora em Python com script Bash, desenvolvido para uma atividade da EBAC.

A calculadora pede para você escolher uma entre 4 operações matemáticas(adição, subtração, multiplicação e divisão) e depois escolher 2 números que você queira calcular na operação matemática, com isso ela faz o cálculo dos 2 números escolhidos e gerando o resultado final da operação. A calculadora tem alguns tratamento de erros, caso você tente fazer divisão por 0 ela vai responder "Erro: Divisão por zero não é permitida.", caso tente escolher uma opção além das 4 operações matemáticas "Opção inválida. Tente novamente." e caso você escolha um número não válido na hora de calcular "Entrada inválida. Por favor, insira números válidos."

chmod 744 calculadora.sh
./calculadora.sh
